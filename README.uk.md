# deep_learning_clothing_classifier

Класифікація зображень на датасеті Fashion-MNIST з порівнянням власної CNN (точність 91.83%) та донавченої VGG16 (transfer learning, точність 92.41%), з використанням аугментації даних, EarlyStopping та планування learning rate. Включає застосунок на Streamlit для завантаження зображень і перегляду прогнозів у реальному часі з рівнем впевненості та графіками навчання.

Застосунок підтримує **українську** та **англійську** мову інтерфейсу, яку можна перемикати в бічній панелі.

## Налаштування ваг моделі

1. Завантажте ваги моделі за [цим посиланням Google Drive](https://drive.google.com/file/d/1UXVYjxOxjt-ZB0cezdNeXF2-K3Bvxp5X/view?usp=sharing).
2. Помістіть файл `vgg16_model.keras` у кореневу директорію проєкту перед запуском Streamlit-застосунку.

## Локальний запуск

```bash
conda activate clothing_classifier
streamlit run streamlit.py
```

Застосунок буде доступний за адресою `http://localhost:8501` (або на іншому порту, який Streamlit виведе в терміналі).

## Запуск через Docker

Побудова образу:

```bash
docker build . -t clothing-classifier
```

Запуск контейнера:

```bash
docker run --name clothing-classification-app -p 8500:8501 -d clothing-classifier
```

Застосунок буде доступний за адресою `http://localhost:8500`.

Перегляд логів:

```bash
docker logs clothing-classification-app
```

Зупинка контейнера:

```bash
docker stop clothing-classification-app
```

> **Примітка:** треновані файли `.keras` не включені до репозиторію та до контексту збірки Docker через їхній розмір. Переконайтеся, що вони присутні в кореневій директорії проєкту (див. розділ *Налаштування ваг моделі* вище) перед побудовою образу або запуском застосунку.

## Структура проєкту

- `streamlit.py` — точка входу застосунку та навігація
- `model_demonstration.py` — основна сторінка: завантаження зображення, прогнози, таблиця результатів, графіки навчання
- `translations.py` — словники текстів інтерфейсу для української та англійської мов
- `functions.py` — допоміжні функції (наприклад, побудова графіків навчання)
- `requirements.txt` — прямі залежності проєкту
- `Dockerfile` — опис збірки контейнера

## Висновок

VGG16 із донавчанням дала 92.41% — трохи краще за власну CNN (91.83%), але без значного стрибка. Спочатку, з повністю замороженою базовою моделлю, точність трималася на рівні близько 85%, а після розморожування block4 і block5 з дуже малим learning rate вона піднялася до 92.41% — тобто саме донавчання дало приріст майже у 7 відсоткових пунктів.
